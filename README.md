# Scoopy – ice cream store (Java, Spring Boot, Thymeleaf)
Requires JDK 17+ and Maven.
    mvn spring-boot:run
Open http://localhost:8080 (on your phone: http://<your-pc-ip>:8080 on the same Wi-Fi).
Stack: HTML (Thymeleaf templates), CSS (static/css/style.css), JavaScript (static/js/app.js), Java (Spring Boot).
Features: product grid, live search, category chips, sorting, AJAX cart (no page reload), toast messages, checkout, order confirmation.
Edit the catalogue in StoreApp.java (class Catalogue).
